# @design-validator/comparator

Deterministic property comparison of matched elements, producing exact `current` / `required` / `delta` differences with configurable tolerances.

**Boundary:** Operates on `DesignSpec` only — no Figma, XD, browser or AI code. Never produces a page score.

**Status:** package boundary only. Implemented in Phase 5 — Comparison Engine (see `phases.md`).
